# 《回留》美术资产约束

当前目录中的人物与背景 SVG 是运行占位资产，不代表最终美术定案。它们的作用是保证资源 ID、场景切换、立绘显示、离线缓存与打包链在正式美术到来前一直可验证。

## 已锁定视觉方向

- 现代中国校园 / 城市 Galgame。
- 日系二维视觉小说语汇，但人物、校服、街道、地铁、住宅与商业空间保持中国语境。
- 角色采用干净线稿、克制赛璐璐上色、少量柔和渐变。
- 禁止把高细节 AI 概念海报、重厚涂、过度摄影感直接作为标准立绘。
- 背景可以比角色稍写实，但仍需二维动画化。
- 正常世界清透克制；异常只在关键场景增加冷色、紫蓝、错位和局部失真。

## 角色生产顺序

1. 标准正面 / 3/4 立绘底模。
2. neutral / smile / worried / surprised / serious 表情差分。
3. 两种常用姿势差分。
4. 私服 / 特殊剧情服装。
5. Q 版。
6. 关键剧情 CG。

差分必须复用同一底模，不允许每张图重新生成导致脸型和服装漂移。

## 六位角色识别点

- 林晚：长黑发、冷灰蓝眼、蓝白校服、气质克制。
- 周小满：暖棕发、琥珀眼、活泼、画具 / Q 版挂件。
- 许栖：银白长发、浅金眼、暗色机能 / 哥特细节、掌机与有线耳机。
- 沈听澜：深茶棕长发、细金属框眼镜、档案本与钥匙。
- 唐梨：红棕高马尾、运动感、橙珊瑚强调色、护膝 / 耳机。
- 乔南星：黑发带深蓝光泽、紫蓝眼、手机、星形小元素。
