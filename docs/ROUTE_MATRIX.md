## 设计约束

- 三条首发路线在第三章末只“开门”，不直接锁死完整结局。
- 主谜题线索应互补，禁止单条路线独占全部世界真相。
- 恋爱剧情必须改变玩家理解角色的方式，而不只是增加好感数值。
- 真结局要求跨路线信息，但不能要求机械刷完所有文本。
