# 《回留 / RESET》v1.1.0 实施与验收

基线：正式 v1.0.1，`25fb3fc220971060cd5d93bbc5d57b319ff852a4`。

## 本版范围

1. 六个手动存档槽：位置、时间、当前台词预览、读取、覆盖确认与删除确认；保留旧快速存读档。存档管理仍调用受保护的 session 接口，战斗和 True Route 不可逆区间无法绕过限制。
2. 结局收藏与 CG 图鉴：13 个正式结局的达成状态；仅解锁已实际阅读的 5 张主线 CG。未达成条目不显示标题和内容剧透；收藏阅读不改变当前进度、读取次数或战斗状态。
3. 自适应阅读布局：1024×768 Windows 窗口、390×844 手机竖屏、844×390 手机横屏、全屏；工具栏始终可用，长文与选项可滚动，弹窗具备焦点管理与 Escape 关闭。
4. 战斗表现：轻重击弧光、命中粒子与闪避残影；遵守“减少动态效果”。保持三处战斗原有难度、数值、碰撞和胜负回接。

## 版本与数据

- 正式版本 v1.1.0，保留 v1.0.0/v1.0.1 标签与公开附件。
- 兼容两版旧存档，继续由引擎重放验证路线；失败读取不计入 Meta。
- 存档槽和收藏在当前站点/Windows 玩家配置中持久化；不删除原快速存档和既有 Meta。
- 引擎保持 `15c101e0d2b2c1e40dbc36d7a0c1a246d102b52c`，不迁移其他游戏。

## 发布门禁

- 主 Build：完整性、全部结局可达性、Meta/不可逆区间、输入队列和新增存档数据逻辑测试。
- 最终 Web ZIP：实际存档槽操作、确认与取消、旧快存兼容、收藏解锁与未解锁内容保护、键盘焦点、三种窗口尺寸、三场战斗实际胜负、真实离线重载。
- 最终 Windows ZIP：原生窗口、直接宿主与启动器链、仅系统 PATH 下运行、手动槽/快速存档/设置/Meta/收藏的进程重启持久化。
- 对照最终 ZIP、公开 SHA256、源码插件、资源清单、版本与文档；全部通过后创建 Release。

## 后续范围

全角色配音、4K 重绘、高预算手绘重制留待单独版本。v1.1.0 聚焦已完成作品的游玩与回收体验。
