# SFX 优化 R1

基线：音乐 R1 后 main `6dbfe14f8a5faf572e9ab7bd9b787c1ae8a31ddd`。
状态：本地信号门禁与 100 项回归通过，平台专项由当前 PR CI 记录；正式公开版本仍为 v1.2.3。

## 范围

保留 7 个音效 ID，重做记忆提示、世界重写、冲击、闪避掠风、快门、未来消息和幽灵门。保留 14 首音乐 R1、全部剧情、既有存档与锁定引擎。

`game/sfx/cues.json` 为音效设计源，`scripts/sfx-design.mjs` 为原创程序合成器；无外部录音或采样。32 kHz / PCM16 / 立体声，单次播放，显式连续起落与非环绕尾音。扫频按频率积分计算相位，替代旧实现的 hz(t) × t。

单声峰值上限 -11 dBFS，反馈起音 15ms 内；短动作冲击与闪避避免旧版缓慢的整段正弦包络。剧情触发校正到实际事件行，避免给“没有声音/提示”或单纯提及往事的句子配音效。

作品级 `sfx.mjs` 提供战斗命中、受击、有效闪避与成功读档反馈。遵循原音效开关及总音量，最多 2 个活动声音，80ms 同音效限流；额外反馈使用 0.5 增益。面板/后台/原生主机暂停、失焦、换场和销毁均停止，恢复不补播旧动作。战斗对话暂停单独允许动作反馈；不改写引擎。

## 验收

按当前 PR 的 Build、最终 Web ZIP 与 Windows ZIP 记录平台结果；不能把信号检查冒称真人试听。物理 Android/Windows 听感不声称已执行。

验收应覆盖：源与字节 SHA256、音效起音/峰值时刻、首尾/削波/DC、音量上限、触发语义与播放一次、恢复/读档不重复剧情提示、实际战斗输入、同音效限流与同时发声上限、播放失败隔离、静音/暂停与断网重载。

- 冲击峰值 126 → 1.781ms，读取峰值 353.125 → 9.469ms；7 个音效首末 PCM 采样为 0，未削波。
- 21 个剧情提示绑定至实际事件行；闪避讲解、椅子转动、未发送消息及“没有系统提示”段落保持静音。
- 14 首音乐及 music-manifest.json 与音乐 R1 逐字节一致。引擎锁、章节、图像、美术验收和存档结构不变。
