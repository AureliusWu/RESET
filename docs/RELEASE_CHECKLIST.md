## v1 阻断规则

`v1.0.0` 只有在以下条件同时成立后才打标签：

1. Web 与 Windows 两条 release CI 均通过。
2. 实时战斗若保留为正式卖点，则至少一场可操作战斗进入发行包；否则明确将当前两场定位为剧情决策战。
3. 所有仍标记为 placeholder/prototype 的关键角色资产要么晋级，要么在发行说明中明确采用极简矢量版视觉并完成一致性验收。
4. True End、六个 Normal End 与关键 Bad End 自动检查通过。
5. 发行包不依赖开发仓库即可运行。
