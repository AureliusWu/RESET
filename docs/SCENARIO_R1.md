# Scenario Reconstruction R1

Status: IN PROGRESS

Goal: rebuild RESET from a structurally complete short VN into a content-complete mid-short Galgame while preserving the existing core mystery, endings, route logic, combat/system contracts, save/meta/gallery behavior, and approved production art.

## R1 acceptance target

- Preserve all existing canonical endings and core mystery answers.
- Preserve VN Engine lock and existing gameplay/system behavior unless a script integration fix is strictly required.
- Build a named supporting cast and a functional NPC layer so Wucheng/campus life exists independently of the six heroines.
- Establish a scene/life-layer bible covering school, family, commute, city, shops, online chat, and ordinary social interactions.
- Reconstruct Chapters 1–7 chapter by chapter rather than padding existing lines.
- Target 80,000–120,000 Chinese Han characters of playable narrative text including choices, with route-aware density and a shared common-route foundation.
- Keep every heroine an independent social actor with relationships and obligations outside Chen Du.
- Keep the existing Normal Ends, key Bad Ends, True Route and True End.
- Run build, release-integrity and regression checks after the reconstructed script is integrated.
- Close R1 only after text-size, route, ending, build and regression acceptance all pass.

## Required production order

1. Freeze canon and route contracts.
2. Build cast bible and relationship graph.
3. Build Wucheng/campus life-layer bible.
4. Re-map current scenes into chapter beats and identify missing daily-life / relationship / tension scenes.
5. Reconstruct common route first.
6. Reconstruct heroine route material.
7. Reconstruct climax, Bad Ends and True Route while retaining existing answers.
8. Integrate script into runtime data.
9. Validate text volume and route reachability.
10. Build + regression + final R1 audit.

## Non-goals

- No engine migration.
- No voice production in R1.
- No random feature expansion.
- No replacement of already-approved core character art solely for novelty.
- No change to the central mystery answer just to create more text.
