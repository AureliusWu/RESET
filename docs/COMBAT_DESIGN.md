# 《回留》轻类魂战斗设计

> 这里保留战斗层的设计原则；当前实装与验收状态以 [制作状态](PRODUCTION_STATUS.md)、`game/combat/`、`game/runtime/combat.mjs` 与自动回归为准。历史阶段版本从 Git 记录追溯。

## 定位

战斗是视觉小说中的剧情高潮模块，不改变《回留》以叙事和角色关系为主体的类型。目标是做出“类魂的学习与死亡循环”，而不是复制完整 3D Soulslike。

当前形态：**2D 单场景 Boss 战**，正式主线包含 3 个实时战斗节点。

## 基础操作

- 移动
- 攻击
- 闪避
- 体力与生命管理
- Boss 学习与跨遭遇状态

不设计复杂连招树、装备刷取和等级碾压。胜利主要来自识别前摇、距离、节奏和阶段变化。

## 与主线的结合

普通游戏中死亡后重试只是机制；《回留》中每次死亡都可以被记录为一次世界事件。

战斗状态通过作品 runtime 与 Meta 层记录尝试次数、结果和 Boss 学习程度，并据此影响后续表现。剧情负责声明战斗入口、胜败出口和叙事后果；碰撞、输入、渲染与状态机由独立战斗模块维护。

## 第一战：无面行人

地点：南湖站封闭员工通道。

它最初看起来只是一个撑伞的人，脸部永远处在看不清的阴影里。第一阶段攻击非常朴素：横扫、突进、停顿后的抓取。玩家死过一次后，许栖会问陈渡为什么提前躲开还没发生的攻击。

重复遭遇后 Boss 会改变原有节奏；受控 UI 提示强调：

> 它正在学习你。

## 六位角色的战斗叙事功能

- 林晚：记忆与下一击残影。
- 周小满：情绪与异常本体感知。
- 许栖：现实 / 夜梧城认知切换。
- 沈听澜：通过资料和记录提供机制判断。
- 唐梨：强调行动、路线与闪避节奏。
- 乔南星：通过信息残响发现异常规律。

这些是剧情化机制方向，不建立传统职业和元素克制表。

## 技术边界

战斗属于《回留》的作品级 runtime 扩展，不把 VN Engine v2 改造成 ARPG。剧情数据只声明战斗节点和分支出口；具体战斗逻辑保持在独立模块中，并通过 VN 状态边界回到主叙事。

## 验收标准

正式战斗节点必须满足：

- 键盘与触摸输入可重复验证；
- 暂停、切后台、隐藏窗口不会继续扣血或重放陈旧输入；
- 死亡和胜利都返回正确 VN 分支；
- 读档不会复制奖励或破坏剧情；
- Boss 学习状态跨遭遇持久化且有上限；
- reduced motion 不改变战斗规则；
- 最终 Web ZIP 与 Windows 原生包均执行真实战斗回归。
