# 《回留》轻类魂战斗设计 · v0.1

## 定位

战斗是视觉小说中的剧情高潮模块，不改变《回留》以叙事和角色关系为主体的类型。目标是做出“类魂的学习与死亡循环”，而不是复制完整 3D Soulslike。

建议形态：**2D / 2.5D 单场景 Boss 战**。

## 基础操作

- 移动
- 轻攻击
- 重攻击
- 闪避（短无敌帧）
- 一个当前角色能力
- 一个消耗道具
- 可选锁定目标

不设计复杂连招树、装备刷取和等级碾压。胜利主要来自识别前摇、距离、节奏和阶段变化。

## 与主线的结合

普通游戏中死亡后重试只是机制；《回留》中每次死亡都可以被记录为一次世界事件。

战斗层需要向未来的 MetaState 抛出：

```ts
{
  battleId: 'faceless-pedestrian-01',
  attempt: 4,
  deaths: 3,
  phaseSeen: ['street', 'station'],
  bossMemory: 2
}
```

VN 层据此修改台词、标题、提示和 Boss 行为。

## 第一战：无面行人

地点：南湖站封闭员工通道。

它最初看起来只是一个撑伞的人，脸部永远处在看不清的阴影里。第一阶段攻击非常朴素：横扫、突进、停顿后的抓取。玩家死过一次后，许栖会问陈渡为什么提前躲开还没发生的攻击。

第三次以后 Boss 开始改变原有节奏；第五次加载时出现受控 UI 提示：

> 它正在学习你。

后期名称可变化为：**无面行人 / 第七次记忆**。

## 六位角色的战斗功能

- 林晚：短暂显示下一次攻击的“残影”。
- 周小满：标出平时不可见的异常本体。
- 许栖：切换现实 / 夜梧城战斗层，改变碰撞与道路。
- 沈听澜：战前通过资料推理揭示一个机制弱点。
- 唐梨：偏近战，拥有更强的完美闪避 / 格挡窗口。
- 乔南星：在限定次数内收到来自未来周目的攻击提示。

这些是剧情化机制，不做传统职业和元素克制表。

## 技术边界

战斗模块应作为 VN Engine v2 的可注册玩法存在，例如：

```text
MiniGameRegistry
└─ combat_soulslike
```

剧情只声明战斗入口、配置、胜败出口；Boss 状态机、碰撞、输入与渲染由独立模块维护。这样可以在没有战斗时继续用纯 VN runtime，并避免把整个引擎改造成 ARPG。

## 验收标准

第一场战斗进入正式 Demo 前必须满足：

- 60 FPS 目标下稳定运行；
- 键鼠与手柄至少一套完整控制；
- 伤害、体力、无敌帧有自动测试或可重复验证；
- 死亡返回 VN 后状态一致；
- 读档不会复制奖励或破坏剧情；
- Boss 至少两阶段；
- 重试会产生一处明确的剧情差分。
