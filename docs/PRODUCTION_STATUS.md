## 正式美术门槛

角色素材只有满足以下条件才能从 `placeholder` 晋级 `production`：

1. 干净线稿 + 克制赛璐璐上色；
2. 同角色脸型、身材、发型、服装结构稳定；
3. 每名主要角色至少 neutral / smile / worried / surprised / serious 五个表情差分；
4. 差分基于同一底模，不允许每张重新生成导致人物漂移；
5. 中国现代校园与梧城环境细节成立；
6. 不使用高细节 AI 概念海报风替代标准 VN 立绘。
