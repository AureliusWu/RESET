# 《回留》声音方向 · v0.2

> 本文描述当前仓库的声音设计与技术基线。稳定发行仍以制作状态、发行说明和最终构建验收为准。

## 总原则

声音不能把作品推成宏大奇幻。正常梧城保留真实、克制、潮湿、日常的听感；异常出现后才逐步引入低频、失稳节拍、金属残响与轻度数字质感。

仓库内音频坚持**原创、可复现、无外部版权依赖**。当前母带由 `scripts/generate-audio.mjs` 程序生成，主要服务于正式运行时配乐、音效与跨平台验收；后续如替换真人演奏或商业母带，必须保持现有动机、资产 ID 与场景语义连续性。

## 技术基线

当前声音生成链要求：

- PCM WAV，16-bit。
- 32 kHz。
- 立体声。
- BGM 最短 12 秒；终局曲目适当延长。
- BGM 使用周期量化振荡器、周期噪声带和无缝动机门控，避免传统“首尾淡入淡出后硬循环”造成的周期性抽吸。
- SFX 使用独立瞬态、扫频、受控噪声和立体声位移，不与 BGM 共用同一套长包络。
- `scripts/check-audio.mjs` 在发行验收阶段直接检查声道数、采样率、PCM 位深、时长、循环接缝、资产引用和 PWA 离线缓存。

## 核心音乐动机

### 18:42 / 回留动机

以少量音级反复出现，通过和声位置、音区和音色变化建立记忆感。正常世界保持清透；异常段落降低音区、增加低频与不稳定脉冲；终局不靠突然加大编制，而靠动机完整度与空间变宽建立“终于走出去”的感觉。

### 日常

关键词：清透、电钢感、轻打击、城市雨声联想、不过度煽情。

### 异常

关键词：低频持续音、远处金属共鸣、节拍缺口、轻度失稳、避免廉价反转音效。

## 角色方向与当前独立主题

- 林晚：`music-linwan-dream` / 《梦里见过你》——玻璃感高频、克制重复、尾部留白。
- 周小满：`music-xiaoman-forward` / 《一直往前走》——更亮、更快，强调向前运动。
- 许栖：`music-xuqi-night` / 《夜梧城》——低频电子与细小数字感，但不做赛博朋克。
- 沈听澜：`music-tinglan-archive` / 《不可信的档案》——纸张/钟摆联想、稳定但带疑点。
- 唐梨：`music-tangli-road` / 《正确的路》——更强推进感与轻脉冲，适合行动段落。
- 乔南星：`music-nanxing-message` / 《明天发来的消息》——颗粒感高频与城市夜景空间。

六位角色的 Chapter 4 主路线已绑定各自主题，避免角色段落长期共用泛用曲。

## 当前通用与终局曲目

- `music-memory-rain`：正常梧城 / 雨中的回忆。
- `music-night-residue`：南湖站、夜梧城与异常低频残响。
- `music-fracture-pulse`：无面行人、战斗与时间断层。
- `music-letter-dawn`：信件、约定与记忆靠近真相的段落。
- `music-seven-chairs`：六人会议、第七把椅子、档案与群像悬疑。
- `music-route-choice`：路线选择与尚未确定的关系段落。
- `music-no-save`：第五章后半至“不保存”不可逆终局。
- `music-tomorrow`：10 月 25 日清晨、True End 与 Ending Credits。

## SFX 体系

当前保留七类高价值叙事音效：

- `sfx-memory-ping`：跨周目、记忆残响、系统异常提示。
- `sfx-load`：读取、世界重写、存档边界变化。
- `sfx-impact`：异常体冲击与实体碰撞。
- `sfx-dodge`：高速掠过与闪避。
- `sfx-camera-self`：异常自拍/快门事件。
- `sfx-message-future`：来自未来或不可能时间点的信息。
- `sfx-door-ghost`：不存在之门、空间边界开启。

音效只放在能改变叙事感知的节点，不追求“每点击一次都响”，避免 UI 游戏化破坏都市灵异的克制感。

## 发行规则

构建前 `scripts/generate-audio.mjs` 自动生成全部 WAV，`game/audio.json` 负责把它们合并进 VN Engine v2 项目。正式构建必须通过 `npm run audio:check`；任何 16 kHz/单声道回退、明显循环爆点、缺失引用或未进入 PWA 离线缓存的音频都会阻断候选验收。
