# 《回留 / RESET》R1 Cast Bible

> Scenario Reconstruction Round 1。核心目标：让梧城成为有人生活的城市，让六位女主拥有陈渡之外的关系，让异常侵入的是一个已经成立的日常世界。

## 核心七人

陈渡、林晚、周小满、许栖、沈听澜、唐梨、乔南星的现有身份、核心谜底、路线与 Ending ID 全部保留。R1 不改“18:42 / 读取残响 / 夜梧城 / 10月24日 / True Route”的既定谜底。

## 常驻配角

- **徐嘉树**：陈渡同桌兼朋友，篮球队替补。嘴快、怕麻烦，但关键时刻不会把朋友独自扔下；负责提供普通男高中生视角和现实校准。
- **程妍**：高二（三）班班长。做事有表格、有截止时间，掌握班群、考勤、活动安排；她代表学校集体秩序，也最先发现“名单和现实对不上”。
- **顾明远**：班主任兼物理老师。三十多岁，习惯先把怪事解释成安全事故或记忆误差；面对学生失控时会先处理现实责任。
- **陈岚**：陈渡母亲，社区医院夜班护士。作息不规律，和儿子的交流常夹在交接班、热饭与未接电话之间；她是陈渡最重要的家庭锚点。
- **许蓉**：梧城一中图书馆管理员，兼管旧校史资料。记得书放在哪一格，也记得谁借过不该存在的册子。
- **罗秀梅**：食堂二楼窗口阿姨。认得常来的学生、谁不吃香菜、谁最近胃口差；她提供最琐碎也最可靠的日常记忆。
- **苏遥**：周小满的美术社好友。行动慢半拍、观察很细，熟悉小满在陈渡之外的生活。
- **何川**：校田径社学长，也是江滩夜跑小队组织者。相信 GPS、配速和打卡记录，直到路线本身开始变。
- **纪尧**：乔南星的信息技术兴趣小组搭档。擅长整理日志和设备时间，不是“万能黑客”，更多负责证明数字记录也会撒谎。
- **林澄**：林晚的表姐，大学一年级。偶尔来校门口等林晚，知道她小时候反复做过同一类雨夜梦。
- **沈砚秋**：沈听澜的姑妈，市档案馆纸质文献修复员。强调来源链、纸张年代和记录责任，不替主角团直接给答案。
- **梁成**：南湖站值班站务员。熟悉封站流程、广播时刻和员工通道；他越普通，异常闯进现实系统时越显得刺眼。

## 使用规则

1. 配角不是线索自动售货机。每个人先有自己的工作、社团、家庭或日程，再因异常受到影响。
2. R5 已为上述 12 名常驻配角建立正式 supporting-cast portrait；普通功能 NPC 仍可无立绘登场。
3. 女主必须至少存在一条陈渡之外的关系：朋友、家人、社团、同事/协作者。
4. 普通 NPC 可以只用功能称谓，但场景里要留下生活逻辑，例如排队、交接班、考勤、借阅、封站、跑步打卡。
5. 配角不得替主角团直接破解核心谜底；他们主要提供现实参照、第三方记忆、后果与阻力。
