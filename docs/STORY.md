# 《回留》故事与结构

## 一句话

梧城一中学生陈渡在连续死亡后发现自己能够“读取”回到固定时刻；当身边六名少女开始保留被覆盖世界的梦、情绪、记录、方向感和信息残响，他必须决定自己是在拯救她们，还是一次次抹去她们已经活过的人生。

## 当前纵切：第一章「雨夜存档点」

时间锚点：**10 月 17 日 18:42**。

陈渡前三次死亡分别发生在山南路、南湖站以及人民公园附近。第四次醒来时，他回到梧城一中旧教学楼，并清楚记得前三次死亡。

开场提供四个方向：

1. 寻找周小满：她并不知道循环，却对陈渡产生来源不明的熟悉和不安。
2. 观察林晚：她的影子与本人不同步，且偶尔梦见被覆盖的周目。
3. 回家：进入 Bad End「家里有人」。
4. 前往南湖站：遇见许栖，她直接问“第四次？”并打开通往夜梧城的门。

进入夜梧城后，故事跳到第二天。现实继续向前，但残响没有消失：沈听澜从档案中发现 18:42 的旧记录；唐梨产生不属于当前世界的路径记忆；乔南星收到由“明天的陈渡”发送的照片；许栖最终告知陈渡：六天后他会再次死亡，而六名少女中有一个人会杀死他。

## 长线结构

建议维持：

```text
共通线
  ↓
林晚 / 周小满 / 唐梨（较早可进入）
  ↓
沈听澜 / 乔南星（条件路线）
  ↓
许栖（多周目后开放）
  ↓
真相线 / True Route
```

六条路线不是六种恋爱口味，而是六种面对“读档”的立场。最终母题集中到三个问题：被覆盖的人生是否存在；拥有互相矛盾记忆的人还是不是原来的自己；当错误可以无限撤销时，选择是否仍然具有意义。

## 恐怖、战斗和超能力

- 灵异恐怖：核心气质之一，优先使用现实轻微错位、城市空间异常、记录矛盾和熟悉事物失真，而不是高频 jump scare。
- 超能力：与人物主题绑定。读档、残响感知、夜梧城通行、异常记录、路径直觉和跨周目信息都是能力体系的一部分。
- 战斗：规划为少量高强度 2D/2.5D 轻类魂 Boss 战；死亡重试与剧情读档统一，但不把主体改造成完整动作 RPG。

## 真结局方向

真结局应让“停止读取”成为真正有重量的行为。玩家和陈渡最后需要接受一个无法保证完美、也不能再次撤销的选择；系统层面的 Meta 表现只在关键节点出现，避免整部作品变成炫技式第四面墙。
