# 演出优化 R1

基线：SFX R1 后 main `cb3b7e92a2f7ad83cc176af6367ad8d958ebf537`。本轮为开发改动，公开版仍 v1.2.3。

## 范围

- 修复章节卡读取 frame.chapter 的无效路径，从 canonical Scene.chapter 获取 7 章信息；只有正常进入新章才出现，读档不重播。
- 标题装饰只属于标题门，不再伴随整段序章对话。
- R1 在打包组合阶段退役旧 stage.effect 全场景遮黑/闪白/整舞台抖动，避免场景效果继承到每一句；不修改章节台词、ID、图像、音频或引擎。
- `game/direction/cues.json` 唯一编排源：15 个有正文锚点的关键节拍、19 个场景氛围覆盖与 7 章字幕。其余场景保留正常阅读和必要的图像淡入。
- 镜头与光影限度：背景位移 ±2px，局部推近最多 1.2%，单次光幕 opacity 不超过 0.2，剧情节拍最长 650ms。常规立绘不移动；没有重复闪烁或强制等待。
- 淡入和节拍等待当前真实图片解码；同一 visit 只触发一次。效果随进入对应台词开始，无需等待打字完成。
- 暂停/面板/隐藏冻结并恢复；换 visit、快进、减少动态或销毁取消旧效果，异步旧图不触发已离开的节拍。读档只还原静态氛围，不重演揭示与章节卡。
- 同时遵循游戏“减少动态效果”和系统 prefers-reduced-motion；恢复动画后不补播旧节拍。效果层 pointer-events:none，不阻塞文字、选项或触控。
- 第六章“没有白光，没有系统提示”保持安静。True End 的既有正文与日期时间不改写。

## 验收

来源与强度、完整包/离线哈希、章节元数据、关键台词锚点与静默段落由门禁验证。真实浏览器和 Windows WebView2 分别验证章节进入、节拍时序、暂停/取消、低动态与输入可用性。保留既有 Web/Windows 包、音乐/SFX、存档/Meta、PWA 与美术回归。

物理 Android/Windows/DPI 不冒称已执行；演出程序检查不改变既有 ART_READY/视觉签收状态。
