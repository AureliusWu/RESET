# 第二章：残响

> 早期设计档案，保留原始阶段描述；文档小版本不代表当前游戏版本。v1.0.0 实装与资产状态以 [制作状态](PRODUCTION_STATUS.md)、[资产状态](ASSET_STATUS.md) 和 [正式发行说明](../CHANGELOG_v1.0.0.md) 为准。

## 章节目标

第二章把“读档”从主角的优势改造成风险来源。玩家第一次遇到会保留跨周目信息的敌对异常体，并确认：世界被读取后，残留的不只恋爱记忆，也包括敌人的学习结果。

## 情绪曲线

1. **日常异样**：林晚记得不存在的约定；周小满只保留死亡现场的情绪。
2. **证据出现**：沈听澜发现一条官方记录中不存在、旧地图却反复标注的下穿通道。
3. **身体记忆**：唐梨没有事件记忆，但身体记得一条已经不存在的路线。
4. **预告死亡**：乔南星收到五分钟后的死亡照片。
5. **首次遭遇**：无面行人出现。它是被读档抛弃的结果之一。
6. **第五次死亡**：玩家若沿用直觉强冲，会死亡并读取。
7. **第二次遭遇**：无面行人改变攻击规律，并说出“又是你”。
8. **章节结论**：死亡不能无限当作攻略工具；每次读取都可能同时强化异常体。

## 首个“类魂感”原型

当前版本仍运行在 VN narrative runtime 上，所以战斗采用剧情化决策验证核心体验：

- 观察攻击前摇；
- 从环境而非本体读取信息；
- 错误选择导致死亡；
- 死亡后保留玩家知识；
- Boss 同样保留部分知识；
- 重复旧解法会被针对；
- 正确思路是重新观察，而不是背板到永远。

真正的实时战斗模块后续接入 VN Engine v2 时，应保持这些叙事语义。

## 无面行人

### 视觉

穿湿透的普通校服或通勤服，五官像被雨水抹平。尽量避免怪物化的大量骨刺、触手和夸张器官；恐怖感来自“它本来应该是一个普通人”。

### 行为规则

- 第一次遭遇：积水倒影比本体早约半秒动作。
- 玩家若利用倒影规律，下一轮它会取消这一前摇。
- 它能逐渐说出读取次数和玩家行为。
- 它不会因为主角死亡而恢复初始状态。
- 它不是传统意义上的恶灵，更像被世界删除失败的“结果”。

## 第三章钩子

章节结束后，陈渡课桌里出现林晚写的信：

> 如果你已经忘了我们的约定，就不要再读档。

关键矛盾：当前周目中的林晚从未和陈渡立下这个约定。
