## Chapter 1 — “先让梧城活着”

保留：第四次读取、周小满/林晚首个残响、南湖站、许栖、夜梧城、沈听澜档案、唐梨路径、乔南星未来照片、10/24 警告。

新增密度：

- `prologue_1842`：18:42 前加入放学留校、赵屿借作业、苏沅催校庆材料、徐培青清教室等正常片段；死亡记忆只在普通声音退去后侵入。
- `xiaoman_rain`：方芸、奶茶店熟客关系、雨伞桶和打烊细节；周小满先作为真实朋友出现，再谈红衣女人。
- `linwan_shadow`：梁初夏与林晚收美术社画具；让“影子先抬头”破坏一段正常创作劳动。
- `after_school_choice`：东门便利店、赵屿消息、陈岚夜班留言；陈渡主动放弃正常回家路线去南湖站。
- `home_bad`：先确认陈渡熟悉的家庭细节，再让门内出现自己的声音。
- `station_fourth` / `station_refuse`：加入魏师傅与真实运营秩序，错误末班广播才有可信基线。
- `night_wucheng`：让陈渡看见现实店铺/公交/广告被“删除结果”重排。
- `morning_after`：班级晨间、赵屿、苏沅、徐培青进入；六女主不再像依次排队报线索。
- `archive_room`：孟知秋与图书馆制度进入；沈听澜的记录观念先落地。
- `cafeteria_path`：刘姨、占座、训练安排、高原消息进入；唐梨先是田径队成员。
- `future_message`：胡一鸣与普通技术排错进入；乔南星先排除缓存/时区/草稿等普通原因。
- `rooftop_warning`：把警告放到一天生活结束后，形成第一次真正“这一周可能被夺走”的重量。

## Chapter 4 — 六条个人路线

### 林晚

生活锚点：梁初夏、美术社、校庆背景板、旧教学楼速写。

路线任务：确认“约定”不只是梦；讨论被覆盖的恋爱是否属于现在的林晚。

Normal End 必须包含：她继续完成自己的画，而不是把人生停在陈渡身上。

### 周小满

生活锚点：苏沅、方芸、班级人际、拍立得计划。

路线任务：把“别人的恐惧”与自己的情绪分开；学习拒绝替所有人维持气氛。

Normal End 必须包含：一张真正属于 10/24 这一轮的普通照片。

### 许栖

生活锚点：魏师傅、二手掌机、旧电玩城、南湖站现实层。

路线任务：证明她不是设定讲解器；她对被删除版本的执念来自具体生活和失去。

Normal End 必须明确其代价：选择夜梧城等于放弃现实中仍在等她的人。

### 沈听澜

生活锚点：孟知秋、志愿组、索引卡、校史整理。

路线任务：从“记录比人可靠”走到“记录用于服务人的记忆，而非取代人”。

Normal End 必须把“空白页”建立在她真正长期整理档案的生活上。

### 唐梨

生活锚点：高原、田径队、训练表、校运会报名。

路线任务：把“向前”从口号变成身体与选择；读取思维与训练伦理发生冲突。

Normal End 必须让她完成一次无法重跑的现实成绩。

### 乔南星

生活锚点：胡一鸣、技术社、广播站姚婧、校庆直播。

路线任务：从“相信数据异常”进入“未来答案会摧毁现在判断”的问题。

Normal End 必须让技术社完成一个没有未来提示的现实任务。

## Chapter 5 — 10 月 24 日

保留：六人会合、城市不同步、北站、第七陈渡、身份问题、锚点真相、请求死亡、18:42。

新增密度：

- 陈岚早班/夜班信息、赵屿借作业、苏沅校庆通知等普通信息继续到达陈渡手机。
- 城市不同步先表现为现实社会的小故障，再升级为空间重叠。
- 配角各自出现至少一次“记忆或记录轻微不同步”，让危机不局限核心七人。
- 北站前必须有一次是否继续把普通人卷入的争论。
- 第七陈渡展示的失败版本要包含具体被放弃的生活，而不只是死亡地点。

## Chapter 6 — 不保存

保留：永久存档 Bad End、不保存、逃离、与失败自我告别、最后一扇门。

新增密度：

- “保存”诱惑应包含让陈渡重新获得母亲、朋友、路线恋情完美版本的可能。
- 拒绝保存后，不只世界崩塌，主角也要接受自己永远无法验证是否存在更好答案。
- 第七人的告别要逐一回应 R1 中建立的普通生活片段，证明失败周目同样发生过。

## Chapter 7 — 明天

保留：10/25、残响消退、林晚江滩、“明天见”、True End。

新增密度：

- 赵屿、苏沅、徐培青、陈岚、梁初夏、方芸、孟知秋、高原、胡一鸣、姚婧、魏师傅至少以现场/消息/对话形式回到生活。
- 六位女主各自继续自己的任务：画、拍照、修掌机、整理校刊、训练、校庆直播。
- 陈渡不再把熟悉台词理解为循环；相似的早晨因细节不同而真正成为新的一天。

## 不可改动的结构契约

- Scene ID 保持稳定。
- Existing choices / next / ending ID 保持稳定。
- 三处实时战斗触发语义保持稳定。
- `bad-home`, `bad-station`, `death-fifth`, `death-sixth`, `bad-no-checkpoint`, `bad-permanent-save` 等既有关键 Bad End 保留。
- 六 Normal End 保留。
- `true-end` 保留。
- 18:42、2009、夜梧城、修正载体、请求死亡、不要保存、不可逆明天等核心答案不改。

## 文本质量门禁

- 禁止把一条旧对白机械扩成十条同义对白。
- 每个场景至少承担两种功能：生活 / 人际 / 情绪 / 信息 / 冲突 / 伏笔 / 决策。
- 同一人物连续 3 句以上纯设定讲解需被拆分为动作、质疑或现实任务。
- 配角至少一半台词不得提供超自然线索。
- 每条个人路线必须出现“女主在做自己的事”，而非等待陈渡到场。
- True End 前必须让玩家明确感到：被放弃的不只是结局，而是已经建立起来的普通一天。
