## 画质策略

新增品牌、章节卡、Q 版徽章和剧情道具采用 **分辨率无关 SVG DOM 几何**，在 1080p、4K、高 DPI 和移动端都由浏览器按目标分辨率重绘，不引入低分辨率位图放大。

这批 SVG 是运行时作品 UI / 道具图形，不作为 `game/assets/*.svg` 旧 production fallback，也不替换现有 58 个已审计的 4K production raster asset ID。因此 Round 8 的“旧正式 SVG 退役”原则保持成立。

PWA 图标继续由代码确定性生成 PNG 192×192 / 512×512，但源几何从引擎通用 N 标识替换为《回留》自己的“回环 + 存档”符号；生成结果可重复并纳入原有安装元数据门禁。
