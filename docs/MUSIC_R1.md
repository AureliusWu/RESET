# 音乐优化 R1

基线：v1.2.3 / `3d323d9125b32611bc2fa5bb50082513658398b9`。
状态：源码、全场景接入与本地信号/回归门禁完成，平台 CI 验收中；当前公开稳定版仍为 v1.2.3。

## 本轮范围

- 保留 14 个 Music ID、7 个 SFX、全部剧情和既有存档结构。
- 原创程序配乐继续采用 32 kHz / PCM16 / 双声道；无采样包、SoundFont 或外部录音。
- 14 首曲目由 12–24 秒固定和弦短循环，扩展为精确按拍的 16 小节 A/B 段落；四组和声、呼吸留白、B 段应答与六种合成音色。
- 六位角色按原曲目身份区分；六个普通结局沿用各自角色主题。全 82 场景显式指定音乐，异常、战斗、日常、终局分别匹配。
- `music-no-save` / `music-tomorrow` 与现有终局引用保留。
- 每个音符、低频脉冲均连续起落；混响尾音环绕循环边界。保留 SFX 生成结果。
- 补充曲中跳变、削波、DC、立体声、空白、循环、能量及来源链校验；实际浏览器验证解码、暂停恢复、同曲连续、静音、设置持久化与离线。

## 来源与运行

`game/music/score.json` 是音乐编排唯一事实源；`scripts/music-score.mjs` 为原创合成器。`npm run audio` 在本地/CI 生成 WAV 和 `music-manifest.json`，运行时字节随最终包一起校验与缓存，不向 Git 提交可重建 WAV。

音乐清单逐曲记录标题、BPM、小节数、音色、循环起止、默认增益及 SHA256。当前引擎使用完整文件循环，故 loopStart=0、loopEnd=frames/sampleRate、defaultGain=1；音乐总音量继续由已有设置控制。

音乐为 16 小节，35.556–64 秒。归一化目标为 -17 dBFS RMS，样本峰值上限 -3 dBFS；RMS 与 LUFS 分开记录，不将能量门禁等同于听感评审。

## 验收记录

- 本地 `npm run build`、`npm run check:release`、`npm run test:release` 通过：90/90 回归，其中 5 项音乐防回退用例。
- 14 曲 × 16 小节，35.556–64 秒；82/82 场景显式映射。7 个 SFX 与 v1.2.3 逐字节一致。
- PCM 样本峰值最高 -3 dBFS；曲间 RMS 差 1.214 dB。循环接缝最大 0.01105，曲中相邻采样跳变最大 0.05829，无削波/空白/DC/单声道退化。
- 独立 FFmpeg EBU R128：-16.4 至 -15.0 LUFS，曲间差 1.4 LU，过采样 true peak 最高 -3.0 dBFS。
- 离线音频共 89,591,132 字节（85.44 MiB），受 96 MiB 门禁约束；未引入需要网络许可的音乐来源。
- 绑定原曲与新曲 SHA256 的对照、PCM 和 EBU 报告在 `docs/evidence/music-r1/`。本地包指纹 `c8ede0713f6bfe`；仅本地证据，不冒充远端最终 ZIP 验收。
- 浏览器真实播放测试与 Windows WebView2 原生解码已接入 CI。本地环境缺少 Playwright 浏览器，平台结果以当前 head 的 GitHub CI 为准，尚待确认。
- 物理 Android/Windows 与真人试听均未声称已执行；信号、解码与播放图通过不等同于主观 OST 终审。

当前音量界面沿用引擎的“音乐与音效音量”及独立语音音量；R1 不宣称已实现 BGM/SE 独立总线或实体设备听感验收。
