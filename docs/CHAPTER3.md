# 第三章：没有发生过的约定

第三轮的目标是把《回留》从“主谜题纵切”推进到真正具备 Galgame 路线选择感的结构。

## 章节推进

1. 陈渡收到由“林晚”写下、但当前林晚从未写过的信。
2. 六人第一次共同验证残响：记忆、情绪、夜梧城三种证据分别对应林晚、周小满、许栖。
3. 三条调查方式提供互相不重复的关键信息：林晚质疑“六人凶手”叙述；周小满确认杀人者没有主观恶意；许栖指出陈渡可能主动请求对方执行死亡。
4. 三线汇合后，乔南星收到“陈渡（已离线）”发来的未来群聊消息。
5. 18:42 的异常自拍重现“六名女生 + 第七把椅子”构图。
6. 新规则出现：**杀你的人不是凶手。不要阻止她，先弄明白你为什么会求她。**
7. 章节末正式开放林晚 / 周小满 / 许栖三条第一阶段调查路线。

## 关系结构

第三章不把六位角色写成六条互不相干的攻略线。沈听澜、唐梨、乔南星在共通线承担证据拼合与团队关系，让三条路线选择发生在一个已经形成互动的角色群里。

后续沈听澜、唐梨、乔南星个人线会在主谜题进一步展开后开放，避免第一阶段一次产生六个平行剧情树。

## 主题推进

第二章证明“敌人会记得读档”；第三章开始证明“爱与承诺也会记得”。

读档造成的问题不再只是不稳定的现实，还包括陈渡不断获得别人没有经历过的感情历史。林晚的信因此第一次明确提出伦理问题：如果某段关系只有读档者记得，它还算发生过吗？
