# v1.3.0 终审与发布验收

用户要求按“剧本文案终审 → UI/UX → 全路线 QA → AI 模拟真人试玩 → Release QA → 新正式版本”推进。

当前为候选审核记录。正式发布仍由同一提交的 Build、严格稳定门禁、最终 Web ZIP 与 Windows ZIP 验收决定；本文件不替代运行证据。

## 文案

基线为 `6f1017c0f24c44fdec18d9af0ce8616c8a161aad`。主要问题是跨场景高频重复、章节三的提纲式叙述、提前复述本场揭示，以及死亡与终局白色空间里错误延续的调查动作。本轮逐场修正，保留全部 ID、行数与选择效果。正文仍遵守单行 80 字符与 8–12 万汉字范围。

## UI / UX

标题页隔离下层控件，焦点初始位于新游戏，Tab 与 Shift+Tab 只遍历可见标题按钮。进入后阅读区接管焦点；读取入口继续打开现有六槽面板。短横屏规则与已有 PWA 44px 下限对齐，仍需实际浏览器检查溢出与操作。

## 全路线

矩阵按完整决定前缀检查，除基本结局可达性外，还检查三种调查方法 × 六条路线分别抵达 Normal End 与 True End。每条路径最多两次进入同一场景，覆盖重试及学习行为；无限次重复死亡不作穷举承诺。

`focus_linwan_open`、`focus_xiaoman_open`、`focus_xuqi_open` 是保留的旧开场，无正式入边，不能冒称从标题可达。其文字与资产单独检查，不通过添加隐藏入口改变剧情。

## 试玩与平台

AI 模拟真人试玩待读取候选运行日志与实际截图后记录观察。自动脚本通过本身不授予新的美术批准，不冒称 owner 或真人受试者。浏览器模拟、Windows CI WebView2、实体设备、主观试听分别记录。

本地容器禁止浏览器通信所需 socket；交互验收在 GitHub Actions 执行。候选阶段不得将这一限制写成浏览器通过。
