# 《回留》视觉方向

> 当前实现状态以 [制作状态](PRODUCTION_STATUS.md)、[资产状态](ASSET_STATUS.md)、[4K 规划](ART_4K_PLAN.md) 与 `game/assets/4k/visual-acceptance.json` 为准；历史阶段变化由 Git 记录保存。

## 已收拢方向

- 现代中国校园 / 城市生活为基础，日系二维视觉小说表达。
- 角色：干净线稿、克制赛璐璐上色、少量柔和渐变；拒绝厚重油画感、摄影级 AI 高细节和过量逆光。
- 背景：比人物稍写实，但仍保持二维动画化。重点表现中国学校、地铁、江滩、老城区、居民区、商业街和普通家庭空间。
- 正常世界：清透、自然、偏低饱和；异常世界：逐渐冷化、紫蓝偏移、局部失真，但不要常态化赛博霓虹。
- 演出：标准 VN 背景 + 透明立绘 + 对话框为主，剧情 CG 只服务关键节点。
- 差分：同一底模保持脸型、比例、发型、服装与饰品一致；表情差分优先于重新生成整个人。
- Q 版：压缩比例但保持发型、配色与关键饰品，不另起一套人设。

## 生产顺序

```text
标准立绘
→ 表情差分
→ 姿势差分
→ 日常服 / 特殊服装
→ 场景背景
→ 剧情 CG
→ UI
```
