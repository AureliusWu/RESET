## 本轮验证中修复的测试问题

- 新 worker 激活前不能只看 registration.active 的 state；必须观察被安装 worker 自己的 activate 事件。
- 固定引擎的 Windows 最小尺寸为 800×600，CI 桌面也有限制；不能把无法创建的请求尺寸当成实际窗口尺寸。
- Playwright 初始化会启用 Emulation.setFocusEmulationEnabled，原生焦点探针前必须显式关闭。
- v1.1.0 标签没有 Pages 专用测试脚本。稳定 ZIP 的 runtime 验证用标签代码，公开网址验证用 main 的 live 脚本及标签生成的 fixtures。
