## Windows 原生验收

windows-latest 从最终 ZIP 启动真实 RESET.exe → engine/VNEngine.exe → game/，游戏进程只保留系统 PATH，无 SDK 覆盖。

- 真实窗口 1024×768、1024×600、宿主最小尺寸 800×600；最大化、最小化与恢复。
- WebView2 内容 DPI 模拟 125% / 150% / 200%，与真实系统 DPI 分开记录。
- 关闭 Playwright 默认焦点模拟后，再用原生前台窗口切换检查失焦；用原生最小化检查后台暂停。
- 完整进程关闭、再启动后，快速/手动槽、设置、Meta、CG、结局继续保留。
- 原生环境无法观测的项目必须进入 acceptance.json 的 limitations；不能用模拟事件冒充真实通过。

## 本轮验证中修复的测试问题

- 新 worker 激活前不能只看 registration.active 的 state；必须观察被安装 worker 自己的 activate 事件。
- 固定引擎的 Windows 最小尺寸为 800×600，CI 桌面也有限制；不能把无法创建的请求尺寸当成实际窗口尺寸。
- Playwright 初始化会启用 Emulation.setFocusEmulationEnabled，原生焦点探针前必须显式关闭。
- v1.1.0 标签没有 Pages 专用测试脚本。稳定 ZIP 的 runtime 验证用标签代码，公开网址验证用 main 的 live 脚本及标签生成的 fixtures。
